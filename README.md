# SyncSpace

SyncSpace is a real-time collaboration web application that allows users to communicate instantly through chat rooms with live updates.  
Built using a full-stack architecture with Node.js, Express, React, MongoDB, and Socket.io.

## Features Implemented

- User Registration with Email Verification
- Secure JWT Login
- Forgot Password with 6-digit Reset Code
- Password Reset with Expiry Validation
- Resend Verification Code
- Resend Reset Code
- Password Hashing using bcrypt
- Secure Authentication Flow
